# 🛡️ Zapret GUI

Запуск [zapret](https://github.com/Flowseal/zapret-discord-youtube) от Flowseal кнопкой, без консоли и меню `service.bat`. Выбрал папку, выбрал стратегию, нажал «Запустить». Обновить сам zapret тоже можно одной кнопкой.

### Быстрый старт

1. Скачай `ZapretGUI.exe` по ссылке выше и запусти.
2. Программа спросит, есть ли у тебя zapret от Flowseal. Есть — укажи его папку. Нет — выбери, куда его поставить, и программа скачает последнюю версию сама. Если папка не пустая (например, Рабочий стол), zapret ляжет в подпапку `zapret-discord-youtube`.
3. Выбери стратегию и нажми «Запустить». Windows спросит права администратора: без них zapret не работает.

Не открывается YouTube или Discord? Попробуй другую стратегию из списка. Какая сработает, зависит от провайдера.

> **Это только обёртка.** Программа не трогает сетевые пакеты — она запускает существующие `general*.bat` из твоей папки. Всю реальную работу с трафиком по-прежнему делает `winws.exe`. В папке zapret программа меняет только две вещи: кладёт туда свою стратегию `general (GUI MAX).bat` (см. [ниже](#экспериментальная-стратегия-gui-max)) и обновляет файлы сборки, но только по твоему подтверждению (см. [Обновление zapret](#обновление-zapret)).

## Требования

| Что | Зачем |
| --- | --- |
| Windows 10 или 11 | запуск `.bat` через `ShellExecute`, настройки в реестре |
| Python 3.9+ | только если запускаешь из исходников, а не из `.exe` |
| Установленный zapret | папка, где лежат `general*.bat` и `service.bat` |
| Права администратора | их запросит сама Windows через UAC при запуске стратегии |

## Установка и запуск

```bash
pip install -r requirements.txt
python gui.py
```

При первом запуске появится стартовый экран с пояснением, что нужно сделать дальше, и кнопкой «Продолжить» — диалог выбора папки не выскакивает сразу, чтобы было понятно, что именно от тебя хотят.

Затем нужно указать папку, в которую распакован zapret — ту самую, где лежат `general*.bat` и `service.bat`. Путь запомнится, и при следующих запусках спрашивать не будут.

## Как это работает

1. Программа ищет в указанной папке все файлы по маске `general*.bat`.
2. Выбранный файл запускается через `ShellExecute` с `verb="runas"` — Windows сама покажет диалог UAC, его нужно подтвердить.
3. `.bat` открывает своё окно `zapret: ...` и уже оттуда крутит `winws.exe`.
4. Раз в секунду программа проверяет через `tasklist`, жив ли процесс `winws.exe`, и по факту его наличия показывает статус «запущено» / «остановлено».

Обычный `subprocess.Popen` здесь не годится: `winws.exe` и WinDivert требуют повышенных прав, и без запроса UAC запуск может тихо не сработать.

## Возможности

- **Автопоиск стратегий** — все `general*.bat` из выбранной папки подтягиваются в список.
- **Свой выпадающий список** — не стандартный `CTkOptionMenu`, а анимированный попап: плавно выезжает вниз, скроллится колесом, закрывается по клику мимо.
- **Индикатор статуса** — бейдж и акцентная полоска сверху, пульсирующие, пока стратегия работает.
- **Последние стратегии** — три последних запуска с кнопкой «запустить снова».
- **Окно лога** (кнопка «📋 лог») — что запускалось, что нашлось, какие были ошибки; новая строка на мгновение подсвечивается.
- **Обновление zapret** — проверка и установка новой версии сборки [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) прямо из программы.
- **Кнопка «⚙ service.bat»** — открывает главный скрипт настроек и диагностики самого zapret (установка службы, тесты стратегий, обновление списков), тоже с запросом UAC.
- **Понятная подсказка** — плашка внизу меняется по ситуации: «выбери папку» → «готово к работе» → «как остановить».

Анимации сделаны на [`easing-functions`](https://pypi.org/project/easing-functions/) — плавные кривые ускорения и замедления, аналог CSS `cubic-bezier`, вместо линейных переходов. Пульсация статуса и подсветка строк лога работают без внешних библиотек, на обычных синусоидах и `.after()`.

## Как остановить стратегию

**Просто закрой окно `zapret: ...`,** которое открылось после запуска.

Отдельной кнопки «Остановить» нет: окно `zapret: ...` и есть сам `winws.exe`, а он работает с правами администратора, так что завершить его из программы можно только через ещё один запрос UAC. Закрыть окно проще. Исключение одно: перед обновлением zapret программа останавливает его сама (см. ниже).

## Обновление zapret

Работает со сборкой [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Под названием папки видна установленная версия (из строки `LOCAL_VERSION` в `service.bat`). При выборе папки программа в фоне сверяет её с `.service/version.txt` в их репозитории, то есть с тем же файлом, который проверяет сам `service.bat`. Если вышла новая версия, кнопка «⬇ Обновить до …» подсвечивается.

Что происходит по кнопке:

1. Программа спрашивает подтверждение. Если zapret запущен, она останавливает его сама: службу `zapret` (если установлена), процесс `winws.exe` и драйвер WinDivert, который держит `bin\WinDivert64.sys`. Для этого Windows один раз спросит права администратора; если отказаться, обновление не начнётся. После обновления (и после неудачного тоже, когда файлы откатились) программа предложит запустить службу или последнюю стратегию обратно.
2. Скачивается `zapret-discord-youtube-<версия>.zip` из релиза на GitHub и распаковывается во временную папку. Архив с путями вида `../` отклоняется. Если внутри нет `service.bat` и `bin\winws.exe` или версия не совпадает с ожидаемой, обновление тоже отменяется.
3. Файлы копируются поверх текущей папки. Всё, что перезаписывается, сначала уходит в резервную копию, и при любой ошибке (например, файл занят) изменения откатываются.

Что сохраняется:

| Что | Как |
| --- | --- |
| `lists\*-user.txt`, `utils\game_filter.enabled` | в релизе их нет, поэтому они не трогаются |
| `bin\ACTIVE_*.bin` (Replace active fakes) | остаются твои |
| `utils\check_updates.enabled` | если ты выключал автопроверку, файл не вернётся |
| режим IPSet `none`/`any` | остаётся, а свежий `ipset-all.txt` ложится в `ipset-all.txt.backup`, откуда `service.bat` берёт его при переключении в `loaded` |

Стратегии `general*.bat`, которых нет в новой версии, не удаляются: вдруг это твои собственные. Список таких файлов пишется в лог. Если была установлена служба `zapret`, в ней остались старые параметры, и её нужно переустановить через `service.bat` → *Install Service*. Программа тоже напомнит об этом в логе.

Хеш архива программа не проверяет: Flowseal не прикладывает к релизам файл с контрольными суммами (они только печатаются в логе их CI). Целостность держится на HTTPS до github.com.

Если папка лежит в `Program Files`, записать туда без прав администратора не получится. Проще перенести zapret, например, в `C:\zapret`.

## Экспериментальная стратегия GUI MAX

Вместе с программой идёт своя стратегия `general (GUI MAX).bat` (исходник в [`strategies/`](strategies)). При выборе папки со сборкой Flowseal программа копирует её туда, и она появляется в общем списке. Если файл в папке отличается от версии в программе, он перезаписывается, так что правки в нём лучше делать под другим именем.

**Она не проверена в реальных сетях.** Это гибрид приёмов, которые уже есть у Flowseal:

- маскировка фейков и хоста под `ya.ru` и `www.google.com` (`fake,hostfakesplit`) — из `general (ALT3).bat`, рассчитана на DPI в режиме белых списков по SNI;
- повышенные повторы фейков (8, для QUIC — 11) — из `general (ALT11).bat`;
- голос Discord с дополнительными фейками и фильтром `unknown` — из `general (EXP).bat`.

Все опции и `.bin`-файлы взяты из сборки Flowseal 1.10.3. Если в новой версии что-то из этого уберут, `winws.exe` не запустится, и окно `zapret: ...` сразу закроется. Против блокировки по IP-адресам не поможет ни эта, ни любая другая стратегия.

Как проверить:

1. Запусти `general (GUI MAX)` и открой YouTube (видео, а не только главную), Discord (текст и голосовой канал) и пару сайтов из `list-general.txt`.
2. Для сравнения сделай то же самое с `general (ALT3)` и `general (ALT11)`.
3. Для честного замера есть `service.bat` → *Run Tests*: он прогоняет все `general*.bat`, включая этот.

Для отчёта нужны провайдер, регион, тип подключения (домашний или мобильный) и что открылось, а что нет. Без этих данных фраза «работает» ничего не значит.

## Сборка в .exe

Двойной клик по `build.bat` — он поставит зависимости и соберёт всё в один файл:

```
dist\ZapretGUI.exe
```

Либо, если нужен контроль над параметрами сборки, есть готовый файл спецификации:

```bash
pyinstaller --noconfirm ZapretGUI.spec
```

Оба способа собирают одно и то же: `--onefile --windowed` с упаковкой `customtkinter` и `easing_functions`.

## Где хранятся настройки

В реестре Windows, в ветке `HKEY_CURRENT_USER\Software\ZapretGUI`:

| Параметр | Что хранит |
| --- | --- |
| `zapret_dir` | путь к папке с zapret |
| `recent_strategies` | последние запущенные стратегии |

Рядом с `.exe` никаких конфигов и временных файлов не появляется. Чтобы сбросить всё к первому запуску, достаточно удалить эту ветку реестра.

## Чего программа не умеет (осознанно)

- Не меняет стратегии Flowseal: обновление zapret заменяет их версиями из официального релиза. Своя у программы только `general (GUI MAX).bat`, её она кладёт в папку сама.
- Не обновляет сборки, отличные от Flowseal (например, оригинальный zapret от bol-van): у них другая структура, и смешивать файлы опасно.
- Не запускает `service.bat` автоматически — только по кнопке.
- Не останавливает `winws.exe` по кнопке: для этого достаточно закрыть окно `zapret: ...`. Сама она останавливает его только перед обновлением.
- Не работает нигде, кроме Windows — на других системах просто скажет об этом и выйдет.

## Частые вопросы

**Это не вирус? Антивирус ругается.**
Исходники открыты, они все в этом репозитории. `ZapretGUI.exe` собирается из них на GitHub Actions: в [логе сборки](https://github.com/EliteSpirit/zapret-gui/actions/workflows/release.yml) видно каждый шаг. Рядом с exe в релизе лежит `ZapretGUI.exe.sha256`, по нему можно убедиться, что скачанный файл тот самый. Антивирусы иногда ругаются на программы, собранные PyInstaller, особенно если они просят права администратора. Можешь сам проверить файл на [virustotal.com](https://www.virustotal.com/). Если сомневаешься, запусти из исходников: `pip install -r requirements.txt`, потом `python gui.py`.

**Список стратегий пустой.**
Выбрана не та папка. Нужна именно та, где лежат `general*.bat` рядом с `service.bat`, а не родительская.

**Нажал «Запустить», ничего не произошло.**
Скорее всего, отклонён UAC — в логе будет строка с кодом ошибки. Запусти ещё раз и подтверди диалог.

**Кнопка «Запустить» неактивна.**
`winws.exe` уже работает. Закрой окно `zapret: ...` — через секунду статус сменится на «остановлено», и кнопка снова станет доступной.

**Стратегия из «последних» не запускается.**
Файл переименовали или удалили из папки — программа об этом предупредит.

### Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it, with one exception described below.

To show whether a newer zapret build is available, Zapret GUI sends a plain HTTPS GET request to `raw.githubusercontent.com` (file `.service/version.txt` of [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)) on startup and when a zapret folder is selected. The request carries no personal data, only the `ZapretGUI` User-Agent; GitHub sees your IP address as with any web request. The zapret archive is downloaded from `github.com` only after you confirm it: either an update or, on first run, the initial download of zapret. Settings are stored locally in the Windows registry.
