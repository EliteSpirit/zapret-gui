# 🖥️ Zapret GUI (обёртка)

Современный тёмный интерфейс (на [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter)) поверх уже установленного **zapret**. Ничего сам не модифицирует в сетевых пакетах — только запускает существующие `.bat`-стратегии из твоей папки zapret. Всю реальную работу с трафиком по-прежнему делает `winws.exe`, который уже стоит у тебя и которому ты уже доверяешь.

## Установка (один раз)

```bash
pip install customtkinter easing-functions
```

## Стартовый экран

При запуске сначала показывается экран с коротким пояснением, что нужно сделать дальше (указать папку, где лежат `general*.bat` и `service.bat`), и кнопка «Продолжить». Это сделано, чтобы диалог выбора папки не выскакивал без объяснения, что именно надо выбрать.

## Как запустить

```bash
python gui.py
```

При первом запуске попросит указать папку, где лежат `general*.bat` (там же, где `service.bat`). Путь запомнится в реестре Windows (`HKEY_CURRENT_USER\Software\ZapretGUI`) — рядом с `.exe` никаких лишних файлов не появляется.

## Кнопка service.bat

Рядом с кнопкой "Изменить" есть кнопка **⚙ service.bat** — открывает главный скрипт настроек/диагностики самого zapret (там же через `ShellExecute` с запросом UAC) — то, через что обычно делают установку, тесты стратегий, обновление списков и т.п.

## Анимации

Используется библиотека [`easing-functions`](https://pypi.org/project/easing-functions/) для плавных кривых ускорения/замедления (аналог CSS cubic-bezier), вместо линейных переходов:
- Стартовый экран плавно проявляется (fade-in всего окна через `-alpha`) и легко въезжает снизу
- Список стратегий — свой анимированный выпадающий список (не стандартный CTkOptionMenu) — плавно выезжает вниз и проявляется, так же плавно сворачивается при выборе
- Пульсирующий индикатор статуса и свечение новых строк лога выполнены без внешней библиотеки (простые синусоиды/цветовые переходы через `.after()`)

## Запуск и права администратора

Кнопка "Запустить" вызывает `.bat`-файл через `ShellExecute` с запросом повышения прав (`runas`) — Windows сама покажет диалог UAC, подтверди его.

## Как остановить

**Просто закрой окно `zapret: ...`**, которое открывается после запуска стратегии. Автоматической кнопки "Остановить" сознательно нет — у `.bat`-скриптов zapret есть свой цикл перезапуска `winws.exe` при падении, из-за которого программное завершение процесса ни к чему не приводит: он просто перезапускается заново. Единственный надёжный способ — закрыть всё окно целиком, поэтому GUI явно на это указывает.

## Что умеет

- Автоматически находит все `general*.bat` в указанной папке
- Выбор стратегии из выпадающего списка
- Индикатор статуса (запущено/остановлено), обновляется каждые 2 секунды по факту наличия процесса `winws.exe`
- Понятная подсказка про то, как остановить

## Чего не умеет (осознанно)

- Не меняет и не создаёт новые стратегии — работает только с тем, что уже есть
- Не запускает `service.bat` (диагностику/установку) автоматически — только по кнопке
- Не пытается программно остановить `winws.exe` — см. причину выше

## Статус

Проверено на работоспособность вручную — запуск, смена стратегии, остановка через закрытие окна.
