Качаешь `ZapretGUI.exe` и запускаешь, Python не нужен. Сам zapret ставится отдельно: программа только запускает `general*.bat` из твоей папки и ничего в нём не меняет.

Этот exe собран на GitHub Actions прямо из исходников репозитория. Контрольная сумма лежит рядом в `ZapretGUI.exe.sha256`.

Если Windows SmartScreen ругнётся, это из-за того, что у сборки пока мало скачиваний, а не из-за содержимого.
