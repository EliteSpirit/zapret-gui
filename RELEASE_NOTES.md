Качаешь `ZapretGUI.exe` и запускаешь, Python не нужен. Сам zapret ставится отдельно, нужна сборка [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).

Что нового:

- zapret можно обновить прямо из программы. Она показывает установленную версию, сама проверяет последнюю на GitHub и после твоего подтверждения ставит новый релиз поверх папки. Перед заменой каждый файл сохраняется в бэкап, при любой ошибке всё откатывается. Твои `*-user.txt` списки и настройки не трогаются.
- Экспериментальная стратегия `general (GUI MAX)`. Программа сама кладёт её в папку zapret. На реальных сетях её толком не проверяли, так что если что-то не открывается, возвращайся на обычные `general`.

Exe собран на GitHub Actions прямо из исходников репозитория. Контрольная сумма лежит рядом в `ZapretGUI.exe.sha256`. Подпись кода предоставлена бесплатно [SignPath.io](https://about.signpath.io/), сертификат — [SignPath Foundation](https://signpath.org/). Если Windows SmartScreen всё равно ругнётся, это из-за того, что у сборки пока мало скачиваний.
